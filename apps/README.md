# Apps made by Claude AppStore

Each folder is one artifact, published to Claude and listed in the store. Open the artifact link in Claude for Mac or Windows and choose *Install as app*.

| App | What it uses | Artifact |
|---|---|---|
| [Focus](focus/index.html) | Menu bar, notifications, global shortcut | https://claude.ai/artifact/34QrCwomkxG1UuEA1C8hFh |
| [Zones](zones/index.html) | Menu bar | https://claude.ai/artifact/3aHTJUDXhT7WrZMSKtcSry |
| [Jot](jot/index.html) | Floating window, global shortcut | https://claude.ai/artifact/XB1iwfcvpd3y43i14i6TMa |

The files are written for the artifact runtime: no `<html>`/`<head>` wrapper, and the desktop features only light up inside the installed app.
