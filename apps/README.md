# AI apps made by Claude AppStore

Stop paying for apps.

Each folder is one artifact, published to Claude and listed in the store. Open the artifact link in Claude for Mac or Windows and choose *Install as app*. Apps call Claude on the viewer's own plan and ask before the first call.

| App | What Claude does | Desktop features | Artifact |
|---|---|---|---|
| [AI Translator](translator/index.html) | Translate, polish, explain, read aloud | Floating window, Option+Shift+T | https://claude.ai/artifact/4YWGk1DexyfRdcmLWD7Wfa |
| [Speaking Coach](speaking-coach/index.html) | Writes lessons, reads them, scores your speaking | Voice, dictation | https://claude.ai/artifact/UuqPyQ25QRBtGaT7E9h3ZD |
| [Party Game](party-game/index.html) | Writes prompts, judges and roasts answers | - | https://claude.ai/artifact/3VqFRic6tuyhhd8mNCTwru |
| [Pomodoro Timer](pomodoro/index.html) | Plans your to-dos into pomodoros | Menu bar, notifications, Option+Shift+P | https://claude.ai/artifact/34QrCwomkxG1UuEA1C8hFh |
| [World Clock](world-clock/index.html) | Answers "when should we meet" | Menu bar | https://claude.ai/artifact/3aHTJUDXhT7WrZMSKtcSry |
| [Sticky Notes](sticky-notes/index.html) | Checklist, clean up, summarize, translate notes | Floating window, Option+Shift+J | https://claude.ai/artifact/XB1iwfcvpd3y43i14i6TMa |

The files are written for the artifact runtime: no `<html>`/`<head>` wrapper, and Claude and the desktop features only light up inside Claude.
